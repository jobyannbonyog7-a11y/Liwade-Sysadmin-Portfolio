# System Administrator Career Portfolio - Ocean Edition

Stack: HTML5, CSS3, vanilla JavaScript. No build step, no database.

## Before submitting
1. Put your photo in `images/` and name it exactly `profile.jpg`.
2. Replace "Your Name" (index.html, js/terminal.js) with your real name.
3. Change the course in index.html (About section) if needed.
4. Open `index.html` (or use VS Code Live Server).

## Files
- index.html          Home, Roles, Skills, Tools, Linux Terminal, About
- css/style.css       Ocean theme, porthole picture frame, wavy section edges, responsive
- js/waves.js         Wave background (click, move the mouse over it, or scroll to make splashes)
- js/translations.js  English / Filipino
- js/terminal.js      Simulated Linux command prompt
- js/main.js          Translator, navigation, cards, effects
